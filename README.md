# Analista de Datos en 30 Días

Bootcamp práctico de análisis de datos desarrollado con proyectos progresivos y herramientas utilizadas en el ámbito profesional.

## Objetivo

Desarrollar habilidades prácticas para recopilar, limpiar, analizar y visualizar datos, construyendo un portafolio público de proyectos.

## Herramientas

- Microsoft Excel
- SQL con SQLite y DBeaver
- Python, pandas, NumPy y Matplotlib
- JupyterLab
- Power BI Desktop
- Git y GitHub

## Proyectos

### 1. Análisis de ventas con Excel
Limpieza, análisis de ingresos y elaboración de informes.

### 2. Análisis de ventas con SQL
Consultas, agregaciones y análisis de una base de datos relacional.

### 3. Dashboard de comercio electrónico con Power BI
Indicadores de negocio, visualizaciones y análisis interactivo.

## Metodología

Aprendizaje progresivo mediante ejercicios prácticos, documentación y proyectos reproducibles.

## Estado

Preparación del entorno completada. Los proyectos se desarrollarán durante el bootcamp.
